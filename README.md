# About program. 
This app is a family movie server app. Made with node.js express. It simulates work of a site where you can watch movie. It has authentication, authorization, real token settings, many requests as js files, database, and so on. Have fun with it!

## How to work with it.
First start download it to your local directory. On your PC. Install dipendencies if needed. Start server with npm start. And try to make a request. Read what it does at the begining of a file.
